# video-gen-journey

> A self-directed curriculum for going deep on video generation and landing a role at a frontier AI lab — OpenAI/Sora, Google DeepMind/Veo, Runway, Pika, Luma, ByteDance, Tencent, Alibaba, Lightricks, Genmo, Higgsfield, Decart, World Labs.

I'm a software engineer (microservices, Angular/React, databases) who spent the last six months building with RAG and agentic AI. I'm now committing to a longer learning arc: the math, the systems, and the engineering specific to video generation.

This repo is the public record of that journey — code, paper notes, training runs, blog-ready writeups. If you're on a similar path, fork it and follow along.

## Where to start

- **`webapp/index.html`** — the learning path itself: 8 phases, 46 concept cards, 27 assignments, ~80 external references. Open in any browser; progress saves to `localStorage`. This is the primary working document.
- **`CLAUDE.md`** — the source roadmap (phases, modes, rules of engagement when using Claude Code as a tutor / paper companion / code reviewer).
- **`phase-N/`** folders — will fill in as each assignment is completed. Each contains code + a short README explaining what worked and what didn't.
