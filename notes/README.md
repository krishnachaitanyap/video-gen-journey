# Notes

Working notes, paper summaries, debugging logs, blog post drafts.

Suggested organization:

- `papers/` — paper summaries (one markdown file per paper, named `YYYY-MM-DD-short-title.md`)
- `blog/` — drafts of public-facing writeups before they go on Substack / HuggingFace / personal site
- `debug/` — gnarly debugging notes worth keeping (anything that took more than half a day to figure out)
- `weekly/` — Friday "what I learned this week" notes (one file per week)

Aim for one paper summary per day during Phase 5 (assignment A22).
